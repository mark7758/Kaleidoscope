## 斗地主小游戏

一个纯前端的单机斗地主小游戏：你 vs 两位 AI 玩家，包含完整牌型判定、叫地主、出牌/不出、提示和人机对战。

### 运行

直接用浏览器打开 `index.html` 即可，无需安装依赖或构建工具。

### 玩法

1. 开局后每人 17 张牌，3 张底牌。选择「叫地主」或「不叫」。
2. 地主拿走 3 张底牌并获得先出牌权；如果都不叫则重新发牌。
3. 点击手牌选中，点击「出牌」；无法压过上家时点「不出」。
4. 支持牌型：单张、对子、三张、三带一、三带二、顺子、连对、飞机（带单/带对）、四带二、炸弹、王炸。
5. 点击「提示」会自动选出一手能压过的牌。
6. 地主先出完牌则地主胜；任一农民先出完牌则农民阵营胜。

### 测试

```bash
node test-doudizhu.js
```

### 文件

- `index.html` — 页面结构
- `styles.css` — 样式
- `doudizhu-core.js` — 牌型判定与出牌搜索（可在浏览器和 Node 中运行）
- `app.js` — 对局流程与 AI 逻辑
- `test-doudizhu.js` — 核心逻辑自测
